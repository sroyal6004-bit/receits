# 기록 장부 — 면세 · 영수증

면세 기록 장부와 영수증 기록 장부를 사진과 함께 기록하는 개인용 웹앱(PWA)입니다.
프레임워크·빌드 없이 `index.html` 하나로 동작하며, 오프라인에서도 쓸 수 있습니다.

## 화면 구성

| 탭 | 입력 항목 | 사진 |
|---|---|---|
| 면세 기록 장부 | 이름, 고객번호, 상담날짜, 진료내용 | 최대 3장 |
| 영수증 기록 장부 | 주문처(쿠팡 · 네이버 · G마켓 · 11번가 · 기타), 주문날짜, 메모 | 최대 3장 |

- 상단 검색창: 면세는 이름·고객번호·진료내용, 영수증은 주문처·메모로 검색
- 영수증 탭은 주문처 칩으로 필터
- 목록에서 항목을 누르면 상세 화면 → **수정** / **삭제**
- 오른쪽 아래 **+** 버튼으로 새 기록 → **저장**
- 사진을 누르면 전체화면 보기(좌우 넘김 · 핀치줌 · 다운로드)
- ⚙ 설정: JSON 백업/복원(사진 제외 · 사진 포함 두 가지)

## 사용하기

1. 폰이나 PC 브라우저에서 앱 주소를 엽니다.
2. 브라우저 메뉴에서 **홈 화면에 추가**(iOS Safari: 공유 → 홈 화면에 추가)를 누르면 앱처럼 실행됩니다.
3. 데이터는 그 기기의 브라우저 안에만 저장됩니다. 브라우저 데이터를 지우면 사라지므로 ⚙ 설정에서 주기적으로 백업하세요.

## 배포 (GitHub Pages)

1. GitHub 저장소 → **Settings** → **Pages**
2. **Source**를 `Deploy from a branch`, 브랜치를 배포할 브랜치(예: `main`), 폴더를 `/ (root)`로 선택 → **Save**
3. 잠시 후 표시되는 주소(`https://<계정>.github.io/<저장소>/`)를 폰에서 엽니다.

로컬에서 확인하려면 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속
(`file://`로 직접 열면 뒤로가기·서비스워커가 동작하지 않습니다).

## 파일

- `index.html` — 앱 전체(UI · 로직 · 스타일)
- `manifest.json` — 홈 화면 설치 정보
- `sw.js` — 오프라인 캐시 · 자동 업데이트
- `icon-192.png`, `icon-512.png` — 앱 아이콘
